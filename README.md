# 📝 To-Do List Web App

A simple, intuitive task management web application built using HTML, CSS, JavaScript, and PHP. This project allows users to register, log in, and efficiently manage their daily tasks. It's designed to help users stay organized, focused, and productive with a clean and responsive interface.

## 🛠️ Technologies Used

- **HTML5** – Structure and content  
- **CSS3** – Styling and layout  
- **JavaScript** – Front-end logic and interactivity  
- **PHP** – Server-side scripting  
- **MySQL** – For storing user data and tasks

---

## ✨ Features

- User registration and login system  
- Secure password confirmation and validation  
- Task creation, editing, and deletion  
- User session management  
- "Remember Me" functionality  
- Clean and responsive UI design
